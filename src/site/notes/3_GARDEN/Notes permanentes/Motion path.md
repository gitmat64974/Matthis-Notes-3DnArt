## La note

Motion path : sélectionner le mesh et la curve, menu [[3_GARDEN/MOCs/ANIMATION\|ANIMATION]] -> constrain -> attach to motion path (options : start ou jsplus)

Permet de faire suivre un objet à un chemin  
[[3_GARDEN/MOCs/ANIMATION\|ANIMATION]] -> constrain -> motion path -> Attach to motion path

Par contre il faut supprimer les keyframes de l’objet qui va suivre le chemin.
