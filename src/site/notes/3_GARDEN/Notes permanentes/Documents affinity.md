## La note

##### Création de documents

Ctrl N ou dans le menu fichier 

**Partie principale :** 
On voit toute sortes de préréglages : imprimer (A4, A3 etc), web (fhd 1080p etc) etc … 

**À droite :** 
Dimensions en pixels, cm, mm etc 

DPI : pour passer d’un format numérique à papier (impression): quantité de pixel (unité numérique) dans un pouce (unité papier). La résolution pour imprimer est 300 en standard. Ce n’est utile que pour imprimer une image numérique. 

Format de couleur : rvb pour écran et cmjn mieux pour l’impression. Le rvb 8(8 bits) permet d’avoir 255 valeurs de rouge, vert et bleu. Le 16 est donc un peu mieux. Le rendu 3D se fait en 32 bits. 

##### Formats de documents affinity

.afphoto : fichier affinity -> enregistrer sous

**Exporter :** 

Psd et Tiff : garde tous les calques etc (passer d’un logiciel à l’autre) (attention d’avoir le même encodage (nb de bits) que le fichier d’origine) 

Png et jpeg : exportation sans calques. Une seule image. 
- Png garde des informations de transparence et ne compresse pas l’image 
- Jpeg : compresse l’image, donc le format le plus léger (la compression peut être réglée)

Autres : 
- EXR : utilisé pour les rendus 3D, stocke beaucoup d’informations (masques etc)
- Pdf : faire plusieurs pages.
