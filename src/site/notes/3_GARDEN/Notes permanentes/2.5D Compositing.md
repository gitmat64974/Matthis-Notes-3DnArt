## La note

#### Scanline Render node

Un noeud 'ScanlineRender' est un Raytracer basique qui rendra votre scène 3D.

Il possède 3 entrées :
- **'bg'**, dans lequel vous définirez la résolution de l'image rendue,
- **'obj/scn'**, dans lequel vous pouvez insérer tous vos GEOs qui seront rendus ;
- **'cam'**, dans lequel vous pouvez insérer la caméra qui sera utilisée pour le rendu de votre scène 3D ;
