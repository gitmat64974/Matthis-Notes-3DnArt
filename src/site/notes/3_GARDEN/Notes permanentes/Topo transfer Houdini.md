## La note 

<iframe title="vimeo-player" src="https://player.vimeo.com/video/429613605?h=f7b02ce037" width="640" height="360" frameborder="0" referrerpolicy="strict-origin-when-cross-origin" allow="autoplay; fullscreen; picture-in-picture; clipboard-write; encrypted-media; web-share"   allowfullscreen></iframe>

On utilise le node topo transfer : 
- template head : une geo de base avec une bonne topo (ça peut etre la template head de houdini)
- target head : la geo à retopo 

Dans ce node on définit dans landmarks (suivre les instructions dans le viewport)

![](https://i.imgur.com/2YWRP37.png)

*G pour switch entre template et target*

En appuant sur G, on déplace les landmarks sur la target geo

Quand tout a l'air ok, on appuie sur solve (toolbar en haut du viewport) 

*On peut également définir des rigid primitives : parties de la template geo qui vont rester telles quelles, par exemple l'arrière du crane, le coup ou les oreilles*
