## La note 

Comment utiliser les images plane dans Houdini comme dans Maya ou autre ? 

Il suffit simplement dans le context obj d’utiliser le node reference image 
Ce node va créer un copnet référencé que l’on pourra bouger dans l’espace 3D, donnant exactement le même résultat qu’une image plane dans Maya
