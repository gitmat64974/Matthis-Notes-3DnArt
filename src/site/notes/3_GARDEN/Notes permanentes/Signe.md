## La note

Les signes ne signifient rien dans l'absolu. Ils fonctionnent de façon : 
- conventionnelle, par habitude sociale 
- contextuelle : un signe prend sens seulement par rapport à tous les autres 

Le signe n'est pas une réalité matérielle, c'est une "construction mentale", une représentation qui résulte de l'activité psychique. Le signe n'est pas la chose représentée : "la carte n'est pas le territoire ". Le signe n'est pas l'objet. 
L'élément d'expression du signe lui-même (son, couleur, forme etc) ne doit pas être conçu comme un phénomène physique mais comme une "représentation mentale" qui résulte souvent d'une perception rendue possible par les sens. 

Selon d'autres définitions, le signe est : 
- quelque chose mis à la place de quelque chose d'autre (le quelque chose peut être une chose perçue ou évoquée)
- représentant d'autre chose qu'il évoque à titre de substitut
