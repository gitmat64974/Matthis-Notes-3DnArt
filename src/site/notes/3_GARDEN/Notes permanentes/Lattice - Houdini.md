## La note 


![Capture d'écran 2026-10-08 224330.png](/img/user/Pi%C3%A8ces%20jointes/Capture%20d'%C3%A9cran%202026-10-08%20224330.png)

C'est très simple : 

- Mettre un bound avec des divisions après sa géo : ce sera la grid de deformation
- Edit la bound 
- Lattice deform node : 
	- 1ère entrée : la géo de base
	- 2e entrée : la grid 
	- 3é entrée : la grid déformée
