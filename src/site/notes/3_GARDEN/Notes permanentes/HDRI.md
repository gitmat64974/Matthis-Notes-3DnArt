## La note

Ce sont des images avec une très grande gamme dynamique. Utilisé avec le [[3_GARDEN/Notes permanentes/DomeLight\|DomeLight]] chaque pixel de l'image HDR sert alors de source de lumière et l’exposure devient alors efficient on appelle ça alors une IBL (Image based lighting). *hdr est juste le type d’image (on peut mettre un png dans une dome light)*

Le soleil est généralement un frein à la création, car la source de lumière directe en dépend pour une plus grande souplesse il est conseillé de le l’enlever.

Les HDR sont aussi utilisé grâce à leur valeurs qui, injecté par exemple dans un [[3_GARDEN/Notes permanentes/Displace\|Displace]], permet de notifier des valeurs plus grande que 0 à 1.  

Un très bon site gratuit : [HDRIs • Poly Haven](https://polyhaven.com/hdris)
