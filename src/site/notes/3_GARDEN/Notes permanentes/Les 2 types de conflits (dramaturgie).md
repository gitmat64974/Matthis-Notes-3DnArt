## La note

• le statique (le perso ne peut rien y faire) 
• le dynamique (qui met le perso en mouvement)

Exemple Titanic : https://www.youtube.com/watch?v=t-FISZyTzZU Jack : conflit statique / Rose : conflit dynamique 

Un [[3_GARDEN/Notes permanentes/Protagoniste\|Protagoniste]] peut vivre du conflit statique mais il est préférable qu’il vive davantage de conflits dynamiques.
