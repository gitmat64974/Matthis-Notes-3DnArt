## La note

##### Raccourcis pour la Navigation

**Fenêtres & UI :**

- **MMB-hold** (Middle Mouse Button) : Permet de faire un Pan2D (translation dans les axes vertical et horizontal)
- **MMB-clic** : Centre la vue sur l'ensemble des nodes
- **MMB-scroll** : Zoom In / Zoom Out
- **LMB-hold** (clic gauche enfoncé) : Trace des zones de sélection ; les nodes doivent être entièrement dans la sélection pour être inclus
- **F** : Centre la vue sur l’élément sélectionné, ou sur l'ensemble des nodes si aucun n'est sélectionné
- **Spacebar** : Expand/Full View du panneau sous le curseur de la souris
- **Alt+S** : Plein écran de la fenêtre active
- **Shift+S** / **S** dans le NodeGraph : Ouverture de la fenêtre de préférences

**Nodes :**

- **V** : Connecte deux nodes sélectionnés successivement
- **TAB** : Ouvre la fenêtre de création d'un nouveau node
- **CTRL** + clic sur le losange jaune d’un lien : Crée un Dot (node circulaire) dans le chemin nodal
- **CTRL+C** : Copier la sélection de node(s)
- **CTRL+K** : Copie clonée d'un node (les données du node originel sont transmises au(x) node(s) cloné(s)) ; **CTRL+V** pour coller la copie et **Alt+Shift+K** pour dé-cloner
- **CTRL+V** : Coller la sélection de node(s)
- **D** : Active/Désactive le node sélectionné
- **CTRL+SHIFT+Drag & Drop** d'un node sur un autre : Remplace un node par un autre

**Utilitaire :**

- **F12** : Vide le Buffer & Cache du Playback (données chargées par image sur la Timeline)
- **F5** : Lance tous les Writes
- **F7** : Lance tous les Writes sélectionnés
- Autres raccourcis : Voir [Keyboard Shortcuts](https://learn.foundry.com/nuke/content/misc/hotkeys_studio.html)

##### Raccourcis pour le Viewer

**Affichage des Channels (Couches) :**

- **R** : Affiche la couche Rouge
- **G** : Affiche la couche Verte
- **B** : Affiche la couche Bleue
- **A** : Affiche la couche Alpha
- **Y** : Affiche la Luminance de l’image

**Connexion entre Viewer & Inputs :**

- **Shift+1, Shift+2, Shift+#** :
    - Si le curseur est sur le Viewer : Affiche le node connecté à l'input 1, 2, ...
    - Si le curseur est sur le NodeGraph : Connecte le node sélectionné à l'input 1, 2, ...
- **NumPad1, NumPad2, NumPad#** :
    - Si le curseur est sur le Viewer : Affiche le node connecté à l'input 1, 2, ...
    - Si le curseur est sur le NodeGraph : Connecte le node sélectionné à l'input 1, 2, ...
