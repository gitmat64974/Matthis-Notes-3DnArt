## La note 

On va faire un workflow simple

---

Il nous faut 2 choses en entrée : 
- La geo
- Les bones 
-> *Par exemple importer un perso mixamo via un fbx character import*

![](https://i.imgur.com/3izBNcu.png)


Node APEX Pack character : 
*Il fait l'équivalent du pack folder + autorig component*
Cliquer sur Add FK and Bone deform components
-> *Là on peut déjà test avec un scene animate voir si on peut déplacer les articulations*

Node AutorigBuilder : 
*N pour reset les transform si on bouge les controleurs pour test*

Il suffit de drag and drop les controls du component catalog sur al version grisée de des bones et les controls vont se créer sur la version de droite
