## La note 

Pour que Houdini reconnaissance le config ACES, il faut faire une manip simple : 

Modifier le fichier houdini.env (documents/Houdini21.0/houdini.env)

Ajouter la ligne : 
`OCIO = "chemin vers le fichier config.ocio"`

Pour vérifier que ça a marché : 
Edit -> color Settings et regarder si le fichier config.ocio a été bien paramétré
