## La note

Selon Truby, un personnage est soit : 
- Le Héros / Protagoniste 
- Un Adversaire / Antagoniste 
- Un Allié 
- Un Personnage secondaire → dans la terminologie de Truby, un personnage secondaire est un personnage qui a simplement une fonction thématique : il apporte du contraste, de la nuance/profondeur au thème

Un Faux adversaire  : le protagoniste et le public pensent que le personnage est un adversaire mais ce n’est pas le cas (Rogue dans HP1, Sirius Black dans HP3) 

Un Faux allié  : semble être ami pour le protagoniste et le public mais est en réalité un adversaire (Maugrey Fol’Oeil dans HP4) 

Ces rôles ne sont pas forcément figés pendant tout le récit. Comme dans la vie.
