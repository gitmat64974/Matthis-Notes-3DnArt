## La note 


Le setup d'abord dans KineFX avant d'arriver dans APEX : 

![Pasted image 20260228011739.png](/img/user/Pi%C3%A8ces%20jointes/Pasted%20image%2020260228011739.png)

1. on donne un name à la géo de base
2. On crée toutes nos blendshapes à part qu'on vient merge ensuite dans un merge packed (qui nomme les **primitives** packées automatiquement en fonction du nom du dernier node, ici Shape01)
3. On envoie tout dans un characterblendshapesadd (rentrer juste le skin name de la géo de base) puis dans APEX


#### APEX Blendshapes Autorig component


![Pasted image 20260228012141.png](/img/user/Pi%C3%A8ces%20jointes/Pasted%20image%2020260228012141.png)

Dans le autorig component en mode blendshapes, il n'y a pas grand chose à rentrer. 

Quelques paramètres utiles : 
- settings -> sliders : pour gérer l'emplacement, la taille, offset, customisation des sliders (*A savoir qu'on peut en créer en géo custom)
- Shape : régler le shape qui bougera dans le slider et sa couleur
