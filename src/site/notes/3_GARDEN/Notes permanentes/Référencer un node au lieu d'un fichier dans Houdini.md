## La note 

Le principe c'est : ``op:`` suivi du chemin absolu du node au lieu d'un chemin de fichier 

Exemple : ``op:/stage/copnet1/null3``

[Use data from a node instead of a file (op:)](https://www.sidefx.com/docs/houdini/io/op_syntax.html)
