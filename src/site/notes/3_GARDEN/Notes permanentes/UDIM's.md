## La note 

1. Faire bien tous ses [[3_GARDEN/MOCs/UV\|UV]] selon le [[3_GARDEN/Notes permanentes/Process des UV\|Process des UV]]
2. Faire le layout des UDIM's en utilisant plusieurs UV tiles. Plusieurs méthodes : 
	1. Avec les options du layout : sélectionner les options qu'on veut puis surtout le nombre de tiles U et de Tiles V (attention : cocher le shell pre scaling : preserve 3D ratios)
	2. Sélectionner un groupe d'[[3_GARDEN/Notes permanentes/UV Island\|UV shells]] -> Transform move (mettre sur 1) et appuyer sur la flèche droite pour bouger et ensemble d'[[3_GARDEN/Notes permanentes/UV Island\|UV shells]] sur l'UV tile d'à côté. Répéter autant que nécessaire 
3. Exporter en fbx (les UDIMs sont automatiquement compris dedans)
4. Texturer et exporter les maps 
5. Importer dans Maya :
	1. Avec le pxrtexture : selectionner la premiere map du groupe d'udim, se mettre en UV tiling mode UDIM (Mari)
	2. Plugin Substance to Maya
	3. Plugin substance -> Apply workflow to image Maps
