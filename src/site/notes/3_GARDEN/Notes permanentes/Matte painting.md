## La note

Le matte painting est un travail réalisé par la combinaison de plusieurs médias (3D, painting, photo etc). 
Mais le matte painting existait déjà avant l’ordinateur : cela consistait à peindre sur une plaque en verre située devant le décor réel (Les temps modernes de chaplin, Star wars etc etc). 
##### Les étapes du matte painting

C’est du coup assez proche des [[3_GARDEN/Notes permanentes/Étapes d’incrustation d’une image dans une autre\|Étapes d’incrustation d’une image dans une autre]], sauf que c’est généralement un assemblage de plusieurs images. C’est donc aussi une forme de [[3_GARDEN/Notes permanentes/Photobashing\|Photobashing]], que l’on peut utiliser dans le matte painting pour incruster de la 3D. 

Les premières étapes sont pour la création d’une même masse, par exemple une créature. 

1. Croquis -> recherches 
2. Recherche d’images -> références 
3. Assemblage grossier -> perspective, proportions 
4. Détourage propre -> Masque ou vectoriel
5. Fusion des éléments d’une même masse -> masques de fusion, outils correcteurs 
6. Colorimétrie et contrastes -> réglages 
7. Accentuation -> netteté ou flou 
8. Grain -> harmonisation du bruit 
9. Ombres et lumières 
10. Incrustation dans le décor -> [[3_GARDEN/Notes permanentes/Étapes d’incrustation d’une image dans une autre\|Étapes d’incrustation d’une image dans une autre]]
11. Intention -> cadrage, vignettage etc
