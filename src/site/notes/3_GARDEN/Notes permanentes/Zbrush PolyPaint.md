## La note 


- **Polypaint** permet de peindre de la couleur directement sur votre modèle, sans avoir besoin de déplier des UV. C’est idéal pour un workflow rapide et créatif. 

- Le modèle doit être en polymesh 3D (make polymesh 3D)
- Utiliser le pinceau paint
- Il est préférable d’avoir un modèle avec une **densité de polygones élevée** pour pouvoir peindre des détails fins et précis.
- Pour remplir tout le modèle d’une couleur de base : choisissez une couleur dans le Color Picker, puis faites Color > Fill Object pour appliquer la couleur sur l’ensemble du mesh
