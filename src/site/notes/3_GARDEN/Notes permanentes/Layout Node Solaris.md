## La note 


Node qui permet d'instancer des assets avec des brushs, exactement comme le foliage tool d'unreal engine

Prototypes : C'est là qu'on dit quels assets USD on veut utiliser pour le layout 
On peut en ajouter manuellement en cherchant les fichiers, ou en ajouter en drag and drop, comme depuis le asset catalog

#### Créer une base de données d'assets usd

Ouvrir le pane Asset catalog (*New pane type -> Solaris -> asset Catalog*)
Créer une nouvelle base de donnée, la sauvergarder où on veut et bien la nommer en .db

Ensuite ajouter des assets USD
