## La note 

En termes généraux, un vecteur up aide à définir un cadre de référence pour construire votre matrice de rotation. Cela peut être utilisé pour maintenir les genoux d'un personnage dans la bonne direction, aligner une particule, maintenir une caméra à la verticale ou servir de base pour calculer les tangentes d'une courbe, etc.

Par exemple, si vous ne disposez que d'un point et d'un vecteur de vitesse, vous pouvez utiliser un vecteur up et des produits vectoriels pour obtenir le reste. Ce vecteur up peut être soit une constante telle que (0,1,0), soit quelque chose que vous dérivez par d'autres moyens, comme la position d'un nul
