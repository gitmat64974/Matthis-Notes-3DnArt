## La note 

RAPID ENVIRONMENT EDITOR:

![](https://loucasrongeart.notion.site/image/attachment%3A9e8b6bd4-79e8-4f75-a9e4-ca0ead9c8827%3Aimage.png?table=block&id=28e706c2-08f3-8016-b7ba-d6be1abb2438&spaceId=3e628503-d5bd-4fb5-85bd-498b69a31994&width=2000&userId=&cache=v2)

RapidEnvironmentEditor is a software that helps managing EnvironmentVariables in a convenient & quick way. You’ll need it in order to use NUKE at home with our current software environment.

Download RAPID ENVIRONMENT EDITOR: [Rapid setup.exe](https://www.rapidee.com/download/RapidEE_setup.exe)

Then launch RapidEnvironmentEditor as Administrator;

![](https://loucasrongeart.notion.site/image/attachment%3A70aeca9c-5340-4b71-9e9b-5a40c2f50dae%3Aimage.png?table=block&id=28e706c2-08f3-8050-8e11-e86620f6274f&spaceId=3e628503-d5bd-4fb5-85bd-498b69a31994&width=2000&userId=&cache=v2)

In your UserVariables, right-Click, and select on ‘Add Variable…’ on the dropping menu:

![](https://loucasrongeart.notion.site/image/attachment%3Aea673686-827a-4762-8c50-4dc0e35d0892%3Aimage.png?table=block&id=28e706c2-08f3-8085-939e-c0defaec4984&spaceId=3e628503-d5bd-4fb5-85bd-498b69a31994&width=1440&userId=&cache=v2)

Name it ‘OCIO’, and set it to ‘String’:

![](https://loucasrongeart.notion.site/image/attachment%3A9f668fad-b629-4119-b19a-d4397a52d669%3Aimage.png?table=block&id=28e706c2-08f3-8057-8492-f8e65726799e&spaceId=3e628503-d5bd-4fb5-85bd-498b69a31994&width=1440&userId=&cache=v2)

Put that text in the Variable value, and press ‘Enter’: C:/Program Files/Pixar/RenderManProServer-26.3/lib/ocio/ACES-1.3/config.ocio

![](https://loucasrongeart.notion.site/image/attachment%3A0409d2ac-ba87-4003-959b-e83dc09fd010%3Aimage.png?table=block&id=28e706c2-08f3-808c-8daa-fac4a9ef9eaf&spaceId=3e628503-d5bd-4fb5-85bd-498b69a31994&width=2000&userId=&cache=v2)

![💡 Icône de l’encadré](data:image/gif;base64,R0lGODlhAQABAIAAAP///wAAACH5BAEAAAAALAAAAAABAAEAAAICRAEAOw==)

You must have RenderMan26 installed on your machine !!

![](https://loucasrongeart.notion.site/image/attachment%3A8148aefd-9ec8-4407-88c8-7bcc34cbc045%3Aimage.png?table=block&id=28f706c2-08f3-8063-8ea4-ff06f857c954&spaceId=3e628503-d5bd-4fb5-85bd-498b69a31994&width=1920&userId=&cache=v2)

### Avoir le .nuke de l'école

Download the school .nuke folder: The entire software environment we have at school is published in this GitHub repository: [GitHub - LRongeart/.nuke](https://github.com/LRongeart/NUKEutilities)

You can download the entire repository by clicking on: ‘Code/Download ZIP’

![](https://loucasrongeart.notion.site/image/https%3A%2F%2Fprod-files-secure.s3.us-west-2.amazonaws.com%2F3e628503-d5bd-4fb5-85bd-498b69a31994%2Ff61d3e71-c2ad-4cd2-9676-12b4092620f6%2Fimage.png?table=block&id=28e706c2-08f3-809e-af24-df6f4c42676e&spaceId=3e628503-d5bd-4fb5-85bd-498b69a31994&width=2000&userId=&cache=v2)

Extract the ‘nuke-main’ folder from the downloaded .ZIP;

Rename this folder to ‘.nuke’;

In your ‘C:/Users/currentUser’, rename the existing ‘.nuke’ folder to ‘.nuke_OLD’ or with a date;

Copy/Paste the new ‘.nuke’ folder to ‘C:/Users/currentUser’;

Now, you can launch‘NukeX.exe’, and it should work right away :D

![](https://loucasrongeart.notion.site/image/attachment%3A82e195b2-fd75-4b08-b376-e927ab3dd4cd%3Aimage.png?table=block&id=28f706c2-08f3-8051-9cf1-e64a8d0b463c&spaceId=3e628503-d5bd-4fb5-85bd-498b69a31994&width=2000&userId=&cache=v2)
