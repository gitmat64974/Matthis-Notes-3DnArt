## La note

Créer un paint layer

Il y a deux éléments principaux dans les brushs : les paramètres de brush (alpha, taille etc) et les paramètres de matières sur lesquels va agir le brush (height, metallic etc)

Pour appliquer des stamps de normal par exemple, il y en a plein dans le shelf dans l’onglet hard surface. En glisser déposer un dans le paramètre de normal d’un brush, le seul activé si on veut que ça.

Ctrl + rmb : taille du brush

Ctrl + lmb : rotation du brush

Il est intéressant aussi de mettre un filtre d’ambiant occlusion sur les hard surfaces détails, ça rend mieux (vérifier juste que le channel source de l’effet soit en normal ou en height, en fonction du brush utilisé).

Enregister le brush : clic droit dans la fenêtre de para métrage : brush (juste infos de brush), matériel (infos de matériel) ou tool (les deux enregistrées)
