## La note

Utile par exemple pour les textes :

On va venir changer l’uv projection en mode planar projection et là on peut changer le translate, rotate et scale avec les mêmes raccourcis que sur maya. On peut aussi utiliser le surface snap (icone fleche vers le bas et cercle en dessous dans la barre d’onglet juste au dessus de la vue 3D qui permet de snap automatiquement sur le modèle 3D en fonction de l’orientation des faces etc.

Par exemple on peut venir masquer un fill layer (avec les paramètres qu’on veut height couleur etc) avec un alpha de texte dans un effet de fill (chercher font dans les alphas) et changer le texte. Puis utiliser la planar projection pour snap le texte sur le modèle 3D
