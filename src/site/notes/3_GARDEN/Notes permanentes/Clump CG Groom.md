## La note 

Permet de venir faire des mèches

#### Exemple avec animal (Xgen)

On met un premier clump avec un mask dans la Density clump pour venir gérer le nombre de clump, qui n'est pas le même partout -> [[3_GARDEN/Notes permanentes/Mask Xgen\|Mask Xgen]].

Dans clump map → radius variance, si on met 3 par exemple ça randomize la taille des clump

On peut rajouter un deuxième clump avec une valeur de densité x2 le clump d'avant (donc des clump bcp plus petites), avec le même mask de densité

On peut jouer avec les paramètres secondaires, surtout de noise : 
![Capture d'écran 2025-01-31 093836.png](/img/user/Pi%C3%A8ces%20jointes/Capture%20d'%C3%A9cran%202025-01-31%20093836.png)

On peut aussi rajouter un noise avant un clump, le clump va essayer de venir suivre un peu le noise
