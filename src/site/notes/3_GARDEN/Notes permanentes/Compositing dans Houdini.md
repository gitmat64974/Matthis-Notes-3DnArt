## La note 

Dans le LOP network de son shot (Voir [[3_GARDEN/MOCs/SOLARIS\|SOLARIS]]), Créer un COP network
Dedans, créer un slap comp block -> ça va import le rendu du LOP network

==Le comp est donc procédural==

De plus, on peut voir en temps réel le résultat de son comp dans le LOP network (activer le petit carré violet) : 

![Capture d'écran 2025-11-15 224327.png](/img/user/Pi%C3%A8ces%20jointes/Capture%20d'%C3%A9cran%202025-11-15%20224327.png)

Cela permet d'ajuster son lighting et de voir le résultat du comp en direct !
