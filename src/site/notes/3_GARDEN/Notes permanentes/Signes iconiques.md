## La note 

Objets et leurs significations, sens connotés (voir la [[3_GARDEN/Notes permanentes/Signes iconiques|Signes iconiques]]) 

#### Classification des signes iconiques selon Pierce

Pierce distingue 3 types de signes iconiques : 
- ***Icône*** : Classe des signes dont le signifiant entretient une relation d'analogie (ou similarité) avec ce qu'il représente (son référent) par exemple une reproduction, imitation du réel (photo, dessin etc). L'icône est un [[3_GARDEN/Notes permanentes/Signe|Signe]] détaché de l'objet mais qui lui ressemble ou le représente de manière figurée. 
- ***Indice*** : Classe des signes sont le signifiant entretient une relation de causalité (contiguïté physique) avec son référent. Par exemple fumée -> feu; nuage -> pluie; empreinte -> semelle; pâleur -> maladie etc
- ***Symbole*** : Classe des signes dont le signifiant entretient une relation arbitraire de convention avec le référent. Colombe -> paix; anneaux -> JO; blanche -> Justice etc. La figure allégorique est par exemple un symbole.
