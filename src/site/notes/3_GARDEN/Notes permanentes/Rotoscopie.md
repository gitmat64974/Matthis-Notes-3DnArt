## La note

Dans NUKE : 

Le ‘Roto’ est un Node qui permet de créer un Matte à partir de Courbes de Beziers. L’ensemble des Courbes créées seront listées dans les Propriétés du node, et peuvent être modifiées de manière non-destructive.
