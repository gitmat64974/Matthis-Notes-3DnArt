## La note

S pour insérer une keyframe 

- Mode ghost (pelure d’oignons) : menu [[3_GARDEN/MOCs/ANIMATION\|ANIMATION]] -> ghost selected et le windows -> ghosting editor

- Motion trail : menu [[3_GARDEN/MOCs/ANIMATION\|ANIMATION]] -> permet de voir les trajectoires de l’objet

- Playblast : clic droit dans la timeline -> playblast

- Muter les axes : très utile pour analyser une anim 

- Keyframe seulement sur un paramètre : clic droit sur le paramètre -> keyframe selected 

Dans le Graph editor : 

sélectionner la portion de courbe puis f : frame la sélection
gérer les tangentes : clic droit break tangents et weighted tangents

Delete by type -> static channels : delete les keyframes qui sont statiques 

mute selected : clic droit sur le paramètre à mute (translate x par exemple)
