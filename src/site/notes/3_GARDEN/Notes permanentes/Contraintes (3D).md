## La note

Les **contraintes** sont des relations qui lient des objets entre eux, permettant à un élément de suivre les mouvements d'un autre.
- **Parent Constraint** : L'élément enfant suit les mouvements de l'élément parent, mais garde son indépendance en termes de transformation. Cela permet de donner à un objet la possibilité de suivre les transformations de plusieurs autres objets. 
	- Parenté classique : sélectionner enfant puis parent puis p
	- Constrain parent : sélectionner parent puis enfant puis parent constrain
		- > maintain offset : maintenir le décalage initial. Si on le décoche les deux objets viennent se coller point de pivot sur point de pivot.
- **Point et Orient Constraint** : Utilisés pour lier la position (point) ou l’orientation (rotation) d’un objet à un autre. Ceci est essentiel pour les animations faciales ou les interactions complexes, comme une main saisissant un objet.
