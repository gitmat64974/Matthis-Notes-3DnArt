## La note 

Le stage manager est un node ultra complet qui permet de réarranger complètement le scene graph (alors qu'il est normalement figé), créer des groupes etc

Il permet aussi de venir récupérer des assets sur le disque, les ajouter à la scène, les transform etc etc

On peut l'utiliser pour rapidement créer un scene graph ou pour en modifier un en milieu ou bout de chaine

*C'est un peu le fonctionnement de l'outliner de Maya mais avec bien plus de possibilités*
