## La note

mesh -> cleanup

Permet :
Éliminer les non quads
Éliminer les laminas (faces superposées)

Options :
cleanup ou select
Le select est mieux prcq le cleanup n’est pas un outil magique. 
Utiliser le cleanup seulement avec les laminas.
On peut donc check les faces à plus de 4 cotes, les concaves, etc

-

Il peut être utile de passer en mode sélection de face par point de centre (paramètres -> sélection -> polygon selection -> center) pour sélectionner les faces plus facilement.

-

L’étape du nettoyage des meshs : [[3_GARDEN/Notes permanentes/Modélisation utilisable en production\|Modélisation utilisable en production]]
