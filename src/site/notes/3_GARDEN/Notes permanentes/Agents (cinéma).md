## La note

Les agents permettent de voir comment est ce que l’histoire évolue.

Les agents sont téliques lorsqu’ils sont proactifs (ils font avancer l’action) ou ateliques (lorsqu’ils ne font pas avancer l’action mais permettent de rythmer la narration. Ils servent toujours à quelque chose). Un même personnage peut être les deux.
