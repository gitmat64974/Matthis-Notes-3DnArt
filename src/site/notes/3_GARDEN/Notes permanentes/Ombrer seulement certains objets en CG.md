## La note

Dans renderman On peut ombrer seulement certains objet ou en exclure certains grâce Au light Linking

![](https://i.imgur.com/JV9U9jy.png)

---

On peut exclure aussi des ombres et de la réflection d’objets à objets avec le Trace Set.
Il faut tout d’abord créer un Set (une sélection sauvegardé), puis copier le nom du set dans l’une de ses catégories dans l’onglet Shadows de la light. Ne pas oublier le cocher Trace set dans le Set.
- Trace Subset : Ombre seulement le Set
- Don’t Trace Subset : Exclu le Set de l’ombrage
