## La note

#### 1. Formulez la **question thématique** du film

- **Exemple** :_Jurassic Park_ → _L’être humain peut-il dompter la nature ?_
#### 2. Identifiez les deux **points de vue opposés** dans le conflit philosophique du film

Dans un tableau, nommez les points de vue et notez leurs arguments principaux.

**Exemple :**

_Jurassic Park_

- **Point de vue 1** : L’être humain et la technologie sont capables de prouesses
- **Point de vue 2** : La nature est incontrôlable


|               | Point de vue 1 | Point de vue 2 |
| ------------- | -------------- | -------------- |
| Avantages     |                |                |
| Inconvénients |                |                |

#### 3. Présentez les personnages principaux en fonction de leur position dans le conflit philosophique

Pour chaque personnage :

1. Précisez leur position dans le conflit (quel point de vue soutiennent-ils ?).
2. Décrivez leur trajectoire au fil du film et l'évolution de leur point de vue, s’il y en a une.

**Exemple :**

_Jurassic Park_

- L'avocat, persuadé que l’exploitation des dinosaures dans un parc d’attractions rapportera une fortune, finit dévoré par le T-Rex, assis sur des toilettes.→ _Victoire du Point de vue 2 sur le Point de vue 1._

#### 4. Quelle est la **ligne thématique** exprimée à l’issue de l’histoire ?

Formulez cette ligne en une phrase claire, en vous appuyant sur les conseils de McKee.

**Exemple :**

_Jurassic Park_ → _Les tentatives de contrôler la nature aboutissent inévitablement à des catastrophes._

#### 5. Donnez votre appréciation et analyse (optionnel)

- Commentaire sur la ligne thématique : **La trouvez vous pertinente ou erronée ? Justifiez votre point de vue.
- Commentaire sur le film : **Partagez votre appréciation générale ou un commentaire spécifique.
