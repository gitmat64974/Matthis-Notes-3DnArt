## La note 

Un node que l'on utilise extrêmement souvent pour les simus notamment. 
-> Export en cache la simu

Dans Houdini $OS = Nom du node
Par exemple le nom du node filecache 

Dans le filecache enlever le $HIPNAME car si on intère / incrémente le cache risque de ne pas être reconnu automatiquement


$S : numéro de la frame


> [!tip]+ Savoir si le cache est chargé
> On a un petit icone en forme de disque dur à côté du node
